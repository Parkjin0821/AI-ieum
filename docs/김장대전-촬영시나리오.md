# 「번거롭게? 아니, 가볍게.」 — 2026 빛고을 사랑나눔 김장대전 메인 숏폼 시나리오 (카톡 → 랩)

> 세로 9:16 · **기준 20~30초** (30초 본편 + 20초 압축본, +6초 범퍼) · 대상: 김장을 결정하는 40~50대 + 함께 오는 가족 · 작성 2026-10-10 (카톡+랩 결합안)
> 구성: **엄마·딸 채팅(공감, 5초) → 랩과 박자 컷(임팩트, 20초) → 다시 채팅(결정, 5초)**. 팀의 카톡 구성안과 랩 안을 합친 것.

> 영상미 기준 2: 괴산군 「2022 괴산김장축제 홍보영상」(youtube.com/watch?v=eZCfmKBoKcs) 0~13초 — 크림색 바탕 위 틀 화면, 한 문장을 1초씩 끊어 띄우기, 핵심 단어만 빨강, 글자 사이 벌린 외침, 그라데이션으로 쓸며 로고·날짜. 같은 '번거로운 김장' 소재라 **말은 겹치지 않게** 연출만 참고.
> 두 영상 모두 **느낌만 참고, 화면은 쓰지 않는다**(권리 있음).

## 1. 한 줄 콘셉트

**11월 김장철, 엄마가 "올해 김장 100포기 할까?" 하고 보낸 카톡에 딸이 답한다. "번거롭게? 아니, 가볍게." 그리고 김장대전 홈페이지 주소.** 주소 아래 뜬 미리보기 사진 속으로 카메라가 들어가는 순간 사진이 살아 움직이며 비트가 터지고, 랩으로 편하게 · 빠르게 · 쉽게를 보여 준 뒤, 다시 미리보기 속에서 빠져나와 엄마의 "예약했다 👍"로 닫는다.

- 40~50대에게: 엄마의 카톡 말투 그대로 — "우리 집 얘기네" 공감 + 10kg 6만 7천 원 실속
- 가족에게: 딸이 먼저 챙기는 이야기 — 함께 가는 김장
- 출연자 얼굴이 필요 없다: 채팅은 화면으로 만들고, 랩은 목소리만, 현장은 **손과 음식**만 찍는다

## 2. 말 — 채팅 + 8마디 랩

96BPM, 4/4박. **1마디 = 2.5초, 1박 = 0.625초.** 채팅 5초(2마디 길이, 비트 없음) + 랩 8마디 20초 + 채팅 5초 = 30초.

**운 구조:** 채팅 마지막 '가볍**게**'가 다리 → 랩은 '장'으로 열고 '게' 세 번(편하게·빠르게·쉽게)으로 몰아친 뒤 '장' 다섯 번(앞장·장갑·사장·상자·끝장)으로 닫는다. 2~4마디 안의 '끝' 세 번이 박자를 찍는다.
**'끝장':** 김장이 '끝'난다 + '끝장나게' 좋다.

### 다른 안 (A/B 테스트용)
- **랩만(이전 안):** "11월은, 김장철." → "근데 우리 집 김장은?" → "번거롭게? 아니, 가볍게." … (가족 얼굴 출연 + 입 맞추기 필요)

## 4. 구조와 템포

```
0s          5s                     15s                   25s        30s
|-채팅(비트X)-|①-랩: 장·게·게·게(②)---|-랩: 장·장·장(③)·끝장-|-채팅·로고--|
 '100포기'    드롭 → 꽉 찬 접사         슬로모 → 손·가족·가격      예약했다 👍
 폰 화면(틀)   박자마다 컷                                     그라데이션
```

**틀 → 꽉 찬 화면 (링크 미리보기로 들어가기):** 채팅은 크림색 바탕 위 폰 화면(틀, 기준 2). 딸이 보낸 홈페이지 주소의 미리보기 사진 속으로 카메라가 들어가 사진이 화면을 꽉 채우고, 그 사진이 그대로 움직이기 시작한다(기준 1의 꽉 찬 접사로). "링크를 열었더니 현장이 살아난다" — 채팅에서 홍보 영상으로 넘어가는 이유가 이야기 안에 있다. 25초에는 반대로 현장이 미리보기 속으로 돌아가 채팅으로 닫는다.

## 5. 컷 대본 (30초)

표기: **화면**(구도·카메라) / **소리** / **글자**(크게=★, 박자 글자=·) / 컷은 박자(0.625초) 단위.

### 채팅 — "올해 김장 100포기 할까?" (0~5초)

| 시간 | 화면 | 소리 | 글자 |
|---|---|---|---|
| 0.0–1.5 | 크림색 바탕 가운데 **폰 채팅 화면**(직접 만든 화면, 방 이름 '엄마 💛'). 엄마 말풍선 도착 | 알림 '띵' | ★ **100포기** (말풍선 밖으로 크게) |
| 1.5–2.8 | 딸 답장 → 엄마 '···' 입력 중 → '…😢'. 폰 뒤로 배추 산·소금 포대 사진이 **회청색으로 흐리게** | 타자 '톡톡' | — |
| 2.8–3.4 | 딸 "번거롭게? 아니, 가볍게." — 노란 말풍선이 '퐁' | 전송음 | ★ **번거롭게? 아니, 가볍게.** |
| 3.4–3.9 | 딸이 주소 kimchigwangju.co.kr 전송 → 아래에 **미리보기 카드**가 붙음(위: 큰 사진 / 아래: 2026 빛고을 사랑나눔 김장대전 · kimchigwangju.co.kr) | 전송음 | — |
| 3.9–4.8 | 채팅 화면 전체가 **미리보기 사진 가운데를 중심으로 커지며** 카메라가 사진 속으로 들어감 (처음 천천히 → 끝에 빠르게) | '슝' 바람 소리 | — |
| 4.8–5.0 | 사진이 화면을 꽉 채움 → **5.0초 사진이 영상으로 움직이기 시작** | **비트 드롭** | — |

> 채팅 화면은 직접 디자인(카카오톡 로고·알림음은 쓰지 않는다 — '카톡 느낌'만). 엄마 말투는 실제 40~50대 카톡처럼 짧게, 말줄임표와 이모지.
> **미리보기 사진 = 랩 1마디 첫 영상의 첫 프레임.** 같은 장면이어야 사진이 '살아나는' 느낌이 난다. 추천 장면: 김치타운 체험관 긴 탁자 위에 절임배추·양념이 펼쳐진 모습을 위에서(행사 홈페이지 대표 사진처럼 보이게). 실제 홈페이지 미리보기 이미지(공식 사진)는 쓰지 않고, **직접 찍은 컷에서 한 프레임을 뽑아** 카드에 넣는다.

### 랩 1 — "11월 김장철, 맛의 고장 광주 김장." (5~7.5초)

| 마디 | 화면 | 소리 | 글자 |
|---|---|---|---|
| 1 | 미리보기 사진이 그대로 움직임(긴 탁자 위 절임배추·양념, 손들이 들어옴) → **빨간 양념 초접사** → 광주김치타운 간판 (박자마다 컷) | 딸 랩 | · 11월 / · **김장철** / · 맛의 고장 / · 광주 **김장** |

### 랩 2~4 — 편하게 · 빠르게 · 쉽게 (7.5~15초) ★②

| 마디 | 화면 | 소리 | 글자 |
|---|---|---|---|
| 2 | 탁자 위 **절임배추 노란 속 접사** → 손이 한 포기 툭 집어 듦 | 딸 랩 | · 절임배추 / · 준비 끝 / · **편하게** |
| 3 | 양념 통 뚜껑이 열리며 **빨간 양념 가득** → 한 국자 떠 올림 | 랩 | · 양념까지 / · 준비 끝 / · **빠르게** |

> 2·3마디는 1박마다 컷, 손의 움직임이 다음 컷으로 이어지게(매치컷). 4마디만 느려진다 — 이 행사의 이득.

### 랩 5~6 — 가족 (15~20초)

| 마디 | 화면 | 소리 | 글자 |
|---|---|---|---|

> 얼굴 없이 **손 크기**로 가족을 보여 준다(큰 손 = 아빠, 작은 손 = 아이). 수육 한 입은 김장 쇼츠 최고 조회 공식(112만 회).

## 6. 20초 압축본 · 6초 편집본

길이 기준은 **20~30초**(레퍼런스로 본 구간이 13~28초). 30초 본편을 기본으로 만들되, 그대로 잘라 20초가 되게 마디 단위로 짠다.

- **20초:** 채팅 0–4 (100포기 → 엄마 허리는? → …😢 → 번거롭게? 아니, 가볍게. → 주소·미리보기 속으로) → 2·3·4마디 4–11.5 (편하게 · 빠르게 · 쉽게) → 7마디 11.5–14 (6만 7천 원) → 8마디 14–16.5 (광주에서 끝장) → 채팅 "예약했다 👍" + 로고 16.5–20. **1마디(11월 김장철)·5·6마디(가족)를 뺀다** — 가족 손 장면(GPT 이미지 자리)이 없어도 완성된다.
- **15초 (필요하면):** 채팅 0–1.5(100포기) → 번거롭게? 아니, 가볍게. → 미리보기 속으로 → 4마디(쉽게.) → 7마디(6만 7천 원) → 8마디(끝장) → 채팅 "예약했다 👍" + 로고.
- **6초 (범퍼 광고):** "100포기 할까?" 1.5초 → "번거롭게? 아니, 가볍게." 2초 → "광주에서 끝장." + 로고 2.5초.

## 8. 편집 지침 — 영상미

- **틀 → 꽉 찬 화면:** 채팅(0~5초)은 크림색 바탕 위 폰 화면 → 링크 미리보기 사진 속으로 들어가 꽉 찬 화면 → 25초에 미리보기 속으로 되돌아 나와 채팅으로 닫는다.
- **박자에 자른다:** 모든 컷은 0.625초(1박)의 배수. 2·3마디는 1박마다, 1·5·6마디는 2박마다, 4마디만 느리게.
- **글자는 박자에 뜬다:** 랩 단어가 들리는 순간 그 단어 하나만 화면에 박힌다(기준 1). 굵은 고딕, 흰 글자+검은 테두리, 운 글자(장·게)와 핵심 단어만 노랑·빨강.
- **전환 효과는 다섯 번만:** 3.9~5초(미리보기 속으로), 12.5초(속도 변화), 22.5초(줌 펀치), 25초(미리보기 밖으로), 28초(그라데이션). 나머지는 그냥 컷.
- **색:** 채팅 배경 사진만 회청색으로 차갑게 → 드롭 뒤 빨강(양념)·노랑(절임배추 속)·초록(배춧잎)이 꽉.
- **음악:** 0~5초는 비트 없이 알림음·타자 소리만. 저작권 걱정 없는 96BPM 힙합 비트(유튜브 오디오 보관함 등), 장구·가야금 샘플이면 지역색이 산다. 25초부터 잦아듦.
- **현장음:** '착'·'쓱쓱'·'딸깍'은 비트 위에 박자에 맞춰 얹는다.
- **AI 활용:** 장면과 목소리는 실제 촬영·녹음. AI-이음은 주제·가사·자막·확인 기록에 쓰고, 영상 설명에 'AI 활용(기획·가사·자막)'을 적는다. AI 생성 인물·장소 없음.
